# #64 지표 — Micrometer Counter/Gauge 신설 (2026-09-01)

## 목적

롱폴링 QR 플로우의 건강 상태를 Prometheus/Grafana 에서 실시간 관측.
알림 유실 41.3% 로 폐기된 push path 대신 pull path 가 실제로 작동하는지 확인하는
핵심 신호.

## 신규 지표

| 이름 | 종류 | 등록 위치 | 설명 |
|---|---|---|---|
| `intent_wait_registered_total` | Counter | `IntentWaitRegistry` 생성자 | 손님이 롱폴링 등록한 횟수 |
| `intent_wait_resolved_total` | Counter | `IntentWaitRegistry` 생성자 | push·poll 양쪽에서 정상 해소된 횟수 |
| `intent_wait_timeout_total` | Counter | `IntentWaitRegistry` 생성자 | 25 s 타임아웃 후 204 반환 횟수 |
| `intent_wait_active` | Gauge | `IntentWaitRegistry` 생성자 | 현재 대기 중인 waiter 수 (AtomicInteger) |
| `notification_dropped_total` | Counter | `AsyncConfig.notificationExecutor` | DiscardPolicy 로 버려진 알림 작업 수 |

## 구현 세부

### `IntentWaitRegistry` 생성자

```java
this.waitRegisteredCounter = meterRegistry.counter("intent_wait_registered_total");
this.waitResolvedCounter   = meterRegistry.counter("intent_wait_resolved_total");
this.waitTimeoutCounter    = meterRegistry.counter("intent_wait_timeout_total");
meterRegistry.gauge("intent_wait_active", activeWaiterCount);
```

`activeWaiterCount` 는 `AtomicInteger` — `gauge()` 가 WeakReference 로 참조하므로
**필드로 유지**해야 GC 되지 않는다.

### 증감 시점

| 이벤트 | 지표 |
|---|---|
| `register()` 호출 | `registered_total` +1, `active` +1 |
| `onCompletion` 핸들러 | `active` -1 (timeout/error/정상 모두 공통) |
| `onTimeout` 핸들러 | `timeout_total` +1 |
| push path `setResult()` 성공 | `resolved_total` +1 |
| poll path `setResult()` 성공 | `resolved_total` +1 |
| DiscardPolicy 실행 | `notification_dropped_total` +1 |

### `notification_dropped_total`

```java
Counter droppedCounter = meterRegistry.counter("notification_dropped_total");
executor.setRejectedExecutionHandler((runnable, pool) -> {
    droppedCounter.increment();
    log.warn("[NOTIFICATION_DROPPED] 알림 스레드풀 큐 포화 — ...");
});
```

F6r 러닝에서 `executor_queued_tasks=64(정원)·active_threads=4(최대)` 로 포화를 실측했고
이 카운터가 그 증거다.

## Prometheus 쿼리 예시

```promql
# 해소율 (push+poll 합산)
rate(intent_wait_resolved_total[1m]) / rate(intent_wait_registered_total[1m])

# 평균 타임아웃 비율
rate(intent_wait_timeout_total[5m]) / rate(intent_wait_registered_total[5m])

# 알림 드랍 속도
rate(notification_dropped_total[1m])
```

## 검증 게이트 (수동)

```bash
# 롱폴링 1개 열기
curl -s http://localhost:8081/actuator/metrics/intent_wait_active
# → measurements[0].value = 1.0

# 해소 후
curl -s http://localhost:8081/actuator/metrics/intent_wait_resolved_total
# → measurements[0].value 증가

# 드랍 확인 (부하테스트 후)
curl -s http://localhost:8081/actuator/metrics/notification_dropped_total
```
