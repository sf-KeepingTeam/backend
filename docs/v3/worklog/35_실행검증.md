### 6. 🔴 D-1 판정

- 승인 알림 발송: **예** ✅
- 근거: qr-service `notif-1` 스레드에서 `PAYMENT_APPROVED` 점주(20001)+고객(10001) 발송 완료. monolith 측 DB 저장 확인 (알림ID 3, 4).
- 수정 내용: `PaymentNotificationListener`의 `@TransactionalEventListener`에 `fallbackExecution = true` 추가 (2곳). `approveSplit()`은 TX 밖에서 이벤트를 발행하므로, `fallbackExecution`이 없으면 리스너가 무시됨.

### 8. APPROVE_PHASE 구간 분해 (로컬 무부하 — 구조 확인용. 절대값은 의미 없음)

**PIN 경로 (기존):**
```
TX_A: 13ms → PIN: 271ms → FUNDS: 210ms → TX_B: 14ms → COMPLETE: 526ms
DB 커넥션 점유: 27ms (TX_A + TX_B)
커넥션 밖: 481ms (PIN + FUNDS)
```

**토큰 경로 (신규):**
```
TX_A: 12ms → PIN_TOKEN: 3ms → FUNDS: 93ms → TX_B: 2ms → COMPLETE: 142ms
DB 커넥션 점유: 14ms (TX_A + TX_B)
커넥션 밖: 96ms (PIN_TOKEN + FUNDS)
```

**구조적 확인**: HTTP 호출(PIN, FUNDS)이 TX 밖에서 실행됨. TX_A/TX_B만 DB 커넥션 점유. 세트 #31이 노린 구조가 실제로 만들어졌다.
