## 2. 🔴 배포 차단 요인 — **없음**

### (A) 미커밋 상태 → 커밋하면 해결

배포 파이프라인은 커밋된 코드만 빌드한다. 커밋 계획은 §6-3에서 제안.

### (B) DB 초기화 → **차단 아님**

`deploy/monolith/docker-compose.yml:44-45`:
```
SPRING_JPA_HIBERNATE_DDL_AUTO=${SPRING_JPA_HIBERNATE_DDL_AUTO:-validate}
```

**첫 배포 시 `.env`에 `SPRING_JPA_HIBERNATE_DDL_AUTO=update`를 설정하면 JPA가 테이블을 자동 생성한다.** v2 신규 컬럼(`expired_settled_at`, `expired_amount`)과 인덱스도 함께 생성된다. 테이블 생성 후 `validate`로 되돌리면 된다.

`mysql/init/02-keeping-test-data.sql`의 INSERT 문은 v2 컬럼을 포함하지 않지만, nullable 컬럼이라 INSERT에 없어도 NULL로 들어간다. **문제 없음.**

schema-agent가 발견한 DDL 결함 3건:
| # | 내용 | 배포 영향 |
|---|---|---|
| 1 | `refund_status` 컬럼 DDL 누락 | `ddl-auto=update`면 JPA가 자동 생성. **차단 아님** |
| 2 | `transaction_unique_no` 길이 불일치 | `update` 모드에서 JPA가 length=200으로 생성. **차단 아님** |
| 3 | `customers.user_key` 컬럼 누락 | `mysql/init/`에 없음. `update` 모드면 JPA가 생성. **차단 아님** |

**결론: `ddl-auto=update`로 첫 배포하면 3건 모두 자동 해결.**

### (C) 빌드 → **통과**

- `compileJava` + `compileTestJava` BUILD SUCCESSFUL (monolith + qr-service)
- `deploy-msa.yml`은 `bootJar -x test`로 빌드 → 테스트 실패가 배포를 막지 않음
- shedlock 의존성: `compileJava` 통과했으므로 Gradle이 정상 다운로드함 확인

### (D) 배포 순서 → **새 DB이므로 제약 없음**

기존 DB 마이그레이션이 아니라 맨바닥에서 시작하므로:
- DDL 먼저 적용할 필요 없음 (`update` 모드가 한 번에 생성)
- restore 제거 순서도 새 배포에서는 무관 (둘 다 동시에 올라감)

## 6. 승인이 필요한 결정

### 6-1. `strict-lot` 초기값 → **off (false) 권고**

근거: 새 DB에 존량 불일치가 없으므로 이론상 on 해도 되지만, 첫 배포에서 예상치 못한 경로가 있을 수 있다. off로 시작하고 대사에서 0 확인 후 전환이 안전하다.

### 6-2. `lazy-enabled` 초기값 → **on (true) 권고**

근거: 측정 대상인 결제 경로에 로직이 추가되지만, 이것이 실제 운영 설정이므로 이 상태에서 측정하는 것이 맞다. on/off 비교는 별도 러닝으로.

### 6-3. 커밋 분할 → **3덩어리 권고**

| 커밋 | 내용 | 이유 |
|---|---|---|
| 1 | 인프라/문서 정리 (docs 이동, .gitignore, deploy 설정) | 코드 변경 없음 |
| 2 | v2 작업 1·2 전체 (세트 #16~#25 코드 + 테스트 + 워크로그 + ADR) | 하나의 논리 단위. 세트별 10개는 과분할 |
| 3 | 도구 상태 (.omc/, .claude/) → .gitignore에 추가하고 커밋하지 않음 | |

### 6-4. CI 빨간불 → **허용 권고**

`ci.yml`은 Docker(Testcontainers)가 필요한 통합 테스트를 돌린다. ubuntu-latest에는 Docker가 있으므로 Testcontainers 자체는 동작한다. CI 실패 시 Actions 로그에서 실제 원인을 확인할 것. 단위 테스트는 전부 통과했고, `deploy-msa.yml`은 `-x test`로 빌드하므로 배포는 영향 없다.

### 6-5. DB 초기화 경로 → **`ddl-auto=update` 첫 기동 권고**

`mysql/init/`을 v2 반영하는 것보다 간단하고 안전. init 스크립트 수정은 나중에.
